# Hoja de ruta P0–P2 — Gestión Gimnasio

Fecha de inicialización: 2026-09-04  
Estado: ejecución incremental

Este documento convierte las auditorías UX/UI y las reglas de `AGENTS.md` en un
backlog ejecutable. Cada ítem debe indicar su Bounded Context, evidencia y estado;
no se considera terminado solo porque compile.

## Criterio de trabajo

- **P0:** puede provocar cobros incorrectos, datos engañosos, bloqueo operativo,
  pérdida de contenido o una brecha de autorización.
- **P1:** afecta tareas frecuentes de recepción o genera errores repetidos.
- **P2:** mejora interpretación, consistencia, escalabilidad o calidad visual.
- Los cambios de Supabase, dominio, pagos, precios, RLS o configuración usan
  obligatoriamente `clean-ddd-hexagonal`.
- El frontend no es una frontera de seguridad: la validación manual debe incluir
  políticas RLS, permisos y una prueba autenticada cuando corresponda.

## Registro de cada entrega

Antes de cerrar un bloque se debe anotar:

1. archivos y contexto modificados;
2. invariantes y contratos afectados;
3. build/pruebas y `git diff --check`;
4. aceptación manual pendiente o realizada;
5. si hubo Supabase, evidencia de RLS, migración o lectura autenticada.
